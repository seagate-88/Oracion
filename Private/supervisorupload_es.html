IMPORTANTE: INSTRUCCION en Español

  • Solo se permiten archivos en formato CSV.
  • El archivo debe contener las columnas en el orden correcto: COUNTRY, STATE, REGION, DATE, FAJR, SUNRISE, DHUHR, ASR, MAGHRIB, ISHA, TAHAJJUD.
    • La columna DATE debe escribirse en formato DD-MM-YYYY. Ejemplo: si la fecha es 1 de junio de 2026, debe aparecer como 01-06-2026.
    • Las horas deben escribirse en formato 24 horas. Si es 6 de la tarde Ejemplo: 18:00.
  • El nombre del archivo debe seguir el formato MM-YYYY.csv. Ejemplo: si el archivo contiene los datos de septiembre de 2026, el nombre debe ser 09-2026.csv
  • Cada archivo representa un mes completo del calendario.

IMPORTANT: INSTRUCTION in English

  • Only files in CSV format are allowed.
  • The file must contain the columns in the correct order: COUNTRY, STATE, REGION, DATE, FAJR, SUNRISE, DHUHR, ASR, MAGHRIB, ISHA, TAHAJJUD.
    • The DATE column must be written in the format DD-MM-YYYY. Example: if the date is June 1, 2026, it must appear as 01-06-2026.
    • Times must be written in 24-hour format. If it is 6 PM, for example: 18:00.
  • The filename must follow the format MM-YYYY.csv. Example: if the file contains data for September 2026, the filename must be 09-2026.csv.
  • Each file represents one full month of the schedule.
